# 0006 — Decisions reopened after full teaching

- **Event**: after the complete 16-command inventory was taught with live
  demos (stamp, explain, matrix, audit, discover, check-structure,
  gen-integrations, and the rest), the user revoked the earlier
  household decisions: "刚才做的决策都不对，我觉得这些似乎都很有用."
- **Reopened**: record 0003 (docs/-only home, capability library
  unbuilt, promote not adopted) and record 0004 (wholesale retirement of
  the specs/ corpus). Both were decided before the command inventory —
  before the user understood what promote/audit/graph/discover do.
- **Process lesson**: grill rounds put to a user before research
  (including the own-codebase half) is fully taught produce invalid
  decisions. Teaching completes first; decisions come last. Records
  0003/0004 stand as history; their decisions are superseded by the
  re-grill that follows.
