# 0002 — Form of the learning half

- **Finding**: research.md F3 (The learning half)
- **Question**: How is the *user's* understanding established — a passive
  review gate, a fact quiz, or an interactive grill?
- **Recommendation**: A grill session grounded in research.md: each
  Finding's decision put to the user one at a time with a recommended
  answer (Pocock grilling: "the decisions are mine"). Checkbox gates are
  fake-able; an interview transcript is not.
- **User's answer**: Confirmed grill, and added the durable trace — grill
  加学习记录: every confirmed round is written to
  learning-records/NNNN-*.md the moment it is confirmed, never batched.
- **Overrides**: Extends the recommendation (records were optional in the
  proposal, mandatory in the answer). Adopted as spec.md Decisions
  "Learning is a grill session plus learning records" and "Learning
  records are written the moment each grill round is confirmed".
